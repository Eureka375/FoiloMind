# FolioMind 功能规格

正式首版以 [系统设计 v2](../FolioMind_System_Design_v2.md) 正文为准。本目录保留早期功能拆分和验收参考。涉及归属数量、云端分析范围、首版优先级或开发顺序时，采用 v2 的规定。

版本 v0.1 · 2026-11-18 · 正式项目的开发规格草案

原始需求见[项目 README](../../README.md)。适用于从正式项目建立 Windows 客户端。此前的 FolioMind_Demo 和实验四交互原型仅用于演示参考，不能作为正式工程的依赖、技术选型或完成证据。

## 先读这三份

1. [全局边界](00-全局边界.md)规定授权、文件操作、支持格式、AI 与数据保护的共同规则。
2. [共享数据与接口](01-共享数据与接口.md)给出跨功能的数据对象、状态、错误和服务契约。每项功能引用这些定义。
3. [开发接入与系统验收](02-开发接入与系统验收.md)说明如何按单篇文档实现、集成与验证，并列出尚未冻结的选型。

最新明确的产品决定优先于旧 README。例如 AI 查询理解留作延后条目，当前 AI 只承担文档理解和分类建议。全局边界优先于功能细节；同层有冲突时先核对源需求，不在两处分别实现。文档中的工程基线是便于开发的可审查默认项；依赖、模型、阈值等选型以待决清单为准。
