## 输入、提取与输出

仅提取授权 .pdf 中已有文字。逐页读取文字层，段落顺序和坐标可用时记录；页号从 1 开始。coverage 至少含总页数（能获取时）、已尝试页数、已提取页和已知无文字或失败页、是否截断。不宣称还原阅读顺序，复杂分栏、错误字形映射等明显异常应给出质量或待人工核验提示。

全篇无可用文字返回 EMPTY/NO_TEXT；只有部分页面可读，或可检测到同页可读部分与图像内容无法覆盖，返回 PARTIAL，保留已提取段。无法可靠判定同页混合或页内覆盖时明确说明。加密（需密码）、损坏、伪造 PDF 头、依赖不可用各自反馈，禁止静默产出“已理解”状态。不执行 PDF 动作、外部链接或嵌入脚本，禁止 OCR。设定文件、页数和耗时预算，到限额按实际覆盖返回。

## 验收

- F07-AC1 文字 PDF 搜索可返回正确页码，PDF 本身保持不变。
- F07-AC2 扫描版无文本，混合文字/扫描页只索引文字页且明确部分覆盖。
- F07-AC3 加密、损坏、页数超限、单页异常有相应状态，不伪造全文覆盖。
