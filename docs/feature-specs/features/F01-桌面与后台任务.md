## 职责与入口

在 Windows 独立窗口提供授权选择、文件清单与状态、分类/标签、搜索及配置。物理整理功能开放后才显示计划、历史、撤销入口。栏目名称与默认入口尚未冻结。首启空状态引导用户选择目录；重启恢复可用配置和已保存分类，缺少模型时标明其能力不可用。

## 流程与契约

- UI 发送应用请求，由应用服务创建 `Job`。任务上下文包含范围、请求参数与提交时版本。成功、取消和失败均向主线程发送结果事件，由 UI 更新视图。
- 每个任务显示阶段、已处理数、失败数；总量未知时显示不定进度。切换页面应保留当前筛选与任务状态。迟到事件以 jobId 判断，不能覆盖新任务页面。
- 取消停止后续项目；正在提交的原子步骤先结束，已完成的计数按实显示。关闭窗口可请求取消并等待安全停点；重启不盲目恢复物理操作。
- 依赖或存储不可用时给出可读错误。模型连接状态不可用不阻塞线下功能。文件系统改动只能走 F15/F16/F18，UI 组件无直接写原文件入口。

## 验收

- F01-AC1 普通用户无需打开浏览器即可启动；无本地模型仍能读取样本文档、分类与搜索。
- F01-AC2 后台任务故意延时，窗口能重绘、展示进度、请求取消，显示部分完成计数。
- F01-AC3 后台先后返回不同任务的消息时，旧结果不能覆盖新任务；重启后配置和分类仍在。
