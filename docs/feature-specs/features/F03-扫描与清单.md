## 职责与流程

输入为有效 scopeId 和授权版本，输出为文件清单和扫描报告。先枚举，再读文件。每到一层目录先判定范围与排除，跳过不安全入口；只把有效候选交给解析器。记录名称、当前路径、格式、大小、修改时间、身份依据和可用性。特征缺失可保留发生状态，不能假报正常。遇到单文件或子目录拒绝访问，报告具体项目并处理其他分支。

对白名单格式按实际可解析性报告结果。非首版类型可在清单以“格式不支持”提示，禁止进入正文处理或 AI。是否展示全部不支持项可由界面筛选，解析覆盖统计须分别计数。目录本身不作为文档进入分析。

## 身份与同步

- fileId 由管理层分配，不以路径、名称或内容哈希直接作主键。重复发现同一访问路径且身份连续时更新既有记录。仅哈希一致的两个副本仍可拥有不同 fileId。
- 操作已确认且结果可靠时保留原 fileId 并更新位置；外部改名只有身份连续且无歧义时才自动关联。身份无法确认则创建新记录，旧记录按失效处理。
- 响应包含已枚举与失败数量、未完整覆盖的分支及是否到达完整扫描终点。取消或权限错误不等同于文件已从磁盘删除，F13 只在确已覆盖的范围推断缺失。

## 验收

- F03-AC1 递归枚举预置样本，排除项和链接不进入解析；对不支持格式显示原因。
- F03-AC2 同一范围重复扫描不会重复产生记录，独立同内容副本不合并。
- F03-AC3 扫描中遇到一项消失、子目录无权限或用户取消，其余结果与未覆盖区域可区分，原文档无变化。
