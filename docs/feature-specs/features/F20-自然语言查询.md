## 当前边界

README 对含糊的自然语言查询提出过模型辅助方案。当前正式范围规定 AI 只负责文档理解与分类建议，因此不实现模型查询解析，不把查询文本发给模型。用户可用关键词和显式筛选。无独立结构解析时，普通输入框把输入作为关键词，不声称理解了意图。

## 后续候选契约

若另行纳入产品范围，输入为查询原文和当前允许的筛选字段，输出仅为可编辑的 QuerySpec 候选、待确认条件及解释。实际检索和授权仍由 F12 完成。查询理解不得生成可执行 SQL、任意路径读取或命令。没有明确日期或来源证据时，“上学期”“老师发的”等不自动补成具体条件。无法理解时展示原文和可编辑条件，保留关键词回退。实现方式与是否使用模型另行决定。

## 验收

- F20-AC1 当前版本输入自然语言或命令样式文本时，不发生模型调用或操作执行。
- F20-AC2 仅未来启用时验证候选字段可审查、可编辑，伪造的名称、路径、日期和来源不会成为有效条件。
- F20-AC3 仅未来启用时验证“包含 Redis 的 PDF”明确展示词与类型过滤，并严格受同一授权边界约束。
