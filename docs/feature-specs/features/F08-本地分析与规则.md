## 职责与输入输出

将标题、有效正文段、已获准文件元信息、分类引用及当前 RuleSet 转换为关键词、候选分组、候选分类及依据。用户可以按已定义的匹配条件配置规则，并可选择把一次修正保存为规则；普通改分类不能自行形成规则。规则版本独立于文档版本，变更只失效受影响的候选建议。

## 计算与边界

- 本地读取、词项归一化、停用词、词权重及匹配可在无模型时运行。算法与中文切词方式待选型；同版本同输入必须能复现结果。
- 工程基线为维度内有序显式规则优先，普通关键词信号补充。等优先或依据不充分时保留多个候选或待确认，不能任意选择唯一类别。持久化人工值不被规则重算覆盖。
- 词项依据保留归一化前的文字与真实段落引用；路径或标题是辅助线索，页面应说明使用了什么字段。无正文时仅用明确可用字段，并标注仅元数据判断。
- 候选组仅作为临时视图，记录成员、证据、生成来源；低相关或无法归组的项保留未归类。结果不直接生成磁盘目录或写入文件。
- 规则的类别引用无效时提示修复，不能绑定同名的新类别。无命中、规则冲突、来源覆盖不足分别反馈，允许人工确认或转 F09。

## 验收

- F08-AC1 相同输入及规则版本重复执行，候选和依据一致；无模型完成。
- F08-AC2 低信息、并列、删除规则指向类别的样本不自动确认为唯一类别。
- F08-AC3 改规则后旧建议失效，人工分类、原路径和内容保持。
