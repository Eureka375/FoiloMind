## 入口与职责

用户从清单或详情进入人工分类，也可批量编辑。类别与标签允许多对多关联。同一文件可同时属于“计算机网络”和“小组项目”；“待确认”是任务状态，不是主题。类别可含主题、课程、用途或项目维度，维度最终清单与界面顺序待定。

## 行为与契约

- 允许新增/重命名类别、增删标签、调整归属、合并或拆分组。改名保持 ID 与已有关系；合并显示受影响关系，去重并更新引用；拆分需显式分配成员，未分配成员明确保留或待处理。删除类别前提示关联和规则影响，原文件不变。
- 提交使用 fileId 和分类/标签 ID，并携带期望 revision。冲突时拒绝过时提交，提示重新载入；批量操作反馈成功、失败与影响项。建议与确认分别保存，接受某项建议属于用户分类动作。
- 保留原建议引用、此前与当前关系、用户确认时间；重算、模型升级与索引刷新不覆写人工值。分类变化只更新分类筛选，不重读文档。
- 方案比较为 P1，候选方案独立版本化，编辑/切换方案只预览，应用前展示归属差异。不要将同一文件复制到多个路径。物理整理另走 F15。
- 是否写成长期规则需用户显式选择。未启用 AI 时仍可完成类别、标签、归属变更。

## 验收

- F10-AC1 一项文件多类多标签，保存、重启并核对原路径和文件数量不变。
- F10-AC2 类别重命名保持关系，合并去重，拆分只更新确认的成员；删除提示关联影响。
- F10-AC3 重算不覆盖用户确认；旧修订拒绝。若启用 P1，取消预览对已确认关系无变化。
