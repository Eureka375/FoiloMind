## 输入、提取与输出

读取授权的 .md 作为文字。使用明确的 Markdown 方言，发布前记录支持的标题、列表、表格等结构。工程基线提取首个文档标题、标题层级和可读正文，保留段落、列表、表格单元格的文本顺序；代码块可作为普通文本检索，禁止执行。返回 segments 和源行定位，有多个标题时保留各自位置。

显示链接文本时不得自动请求链接；本地相对引用、关联附件、图片和嵌入 HTML 都不得触发文件读取或执行。允许提取图片替代文本并标明其来源；图片自身不提取。解析不支持的语法时，可保留原文本或报告覆盖限制，不能伪装成完整结构化结果。空文件、编码错误、超限分支采用 F04 与共享状态。

## 验收

- F05-AC1 含标题、列表、代码块、表格的样本能搜索可读文字并核对源行。
- F05-AC2 含远程链接、本地引用、HTML 脚本或特殊 URI 的样本不会产生额外网络和磁盘读取，也不会执行脚本。
- F05-AC3 无标题仍可提取正文；空白、错误编码及限额截断均以对应状态返回。
