## 存储职责

在当前 Windows 用户可写应用数据目录持久化范围、配置、文件记录、分类、标签、建议、索引引用和任务记录。安装目录无需可写。按用户存储隔离；首版不承诺云同步。选定数据库后给出架构版本、迁移和失败处理，不能在迁移异常时静默清空记录。配置写入保证事务或等效原子替换。

## 数据保护与用户操作

- 分类/标签和用户选择是权威记录，索引/正文缓存/模型结果是派生信息；明确分别保存哪些、用途、可清理状态和保留期。普通日志禁止写正文、载荷、凭据及不必要的绝对路径；操作日志所需路径按权限单独展示。
- 显示“取消管理”和“清理本地派生数据”区别。撤销后先让当前范围数据立即不可见；清理按选择处理正文、索引、摘要和日志，跨范围任务只处理授权范围相关项，保留或删除历史的影响提前提示。原文件路径、内容与数量不变。
- 清理过程中阻止同版本任务重新创建相关数据；失败逐项反馈，允许重试。如果软件未实现可验证的物理擦除，只说明应用从其活动存储移除，不承诺 SSD、安全备份等底层删除。
- 存储不可用时明确哪类操作失败；不假报持久化完成。日志压缩或清理不得掩盖尚未核对的物理任务，撤销证据无法保留时要告知撤销影响。

## 验收

- F14-AC1 普通账号、只读安装位置下可保存配置与分类，重启恢复；模拟写失败不显示成功。
- F14-AC2 撤销范围后立即查不到内容；执行清理后检查活动存储没有所选派生记录，原件哈希和路径不变。
- F14-AC3 日志不含预置的正文敏感标记，迟到的缓存写入不会复活已清理数据。
