## 职责与输入输出

用户在桌面端显式选择根目录，查看并编辑排除规则。授权服务保存规范化根路径、根标识、政策版本和状态，可返回允许、排除、拒绝及原因。选择目录或读取授权不会产生物理写授权。

## 规则与时序

- 增加前校验入口存在、可枚举、路径边界可确认。目录变更时重新判断根身份。路径相等与包含采用 Windows 文件系统语义与组件边界；字符串前缀不能当授权判断。
- 规范化输入后，先应用全局保护边界，再匹配范围排除规则。工程基线支持范围相对路径、目录子树、文件名/后缀或明确通配规则，界面展示匹配类型和示例；排除优先，无隐式包含例外。保护系统目录、代码工程结构、应用数据；不跟随重解析点。
- 同一物理目录拒绝重复配置。父子范围并存时按单个访问路径去重，采用最具体有效范围作为记录归属；路径上任一有效策略的排除优先，不能借重叠授权绕过。撤销范围后立即隐藏其所属记录；若父范围仍显式允许，需新扫描重新确认归属，不能直接重新发布已撤销数据。
- 增加、撤销范围或修改其策略时推进全局 scopeEpoch；已有范围的策略变动也推进它的 policyRevision。这样父范围策略变化也能使使用旧判定的子范围任务失效。服务在文件打开、模型输入和结果提交前复核快照。取消管理立即停止范围可见性，再由 F14 处理派生记录；不会移动、改名或删除原件。

## 验收

- F02-AC1 排除子目录时读取探针不收到其中任意内容请求；对索引和模型输入同样无结果。
- F02-AC2 相似路径前缀、范围外链接、重叠授权均不能绕开排除；范围内不重复展示同一访问路径。
- F02-AC3 在任务未结束时撤销授权，迟到提交被拒绝，搜索立即无该范围结果，原文件保持不变。
