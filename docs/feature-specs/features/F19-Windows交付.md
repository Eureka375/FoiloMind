## 交付边界

提供从 Windows 启动的可执行包或安装形式，能通过独立窗口使用。最低 Windows 版本、架构、包形式、运行时及升级卸载策略待选型；不承诺内置模型服务。发行包应带齐四格式基础解析所需运行组件，不能要求普通用户自行完成开发环境安装后才能读取四种文件。

## 首启与升级

- 首次启动检查本地数据目录可写性、解析依赖及可选模型连接，清楚报告缺项和修复入口。模型缺少只影响 AI 能力，基础管理不受影响。
- 文档说明获取依赖/模型是否需要网络、模型在哪里运行及不联网时的能力。检查数据迁移，失败不清空用户分类或配置。卸载是否清理派生数据由交付方案单独说明，始终不删除被管理的原文档。
- 在全新、普通权限的目标机器上验证启动，默认导航仅呈现版本实际提供的模块；未通过安全验证的真实写入入口隐藏或明确禁用。

## 验收

- F19-AC1 未安装 Python 开发环境的目标机通过发布入口启动，普通用户可持久化数据。
- F19-AC2 模型服务关闭时四格式读取与基础搜索可用，依赖缺失有真实诊断。
- F19-AC3 安装、重启、升级后的分类/配置行为符合说明；升级失败保留原数据，原文档不受影响。
