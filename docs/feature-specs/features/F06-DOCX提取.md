## 输入、提取与输出

输入为授权的 .docx 及读取预算。通过隔离的正文解析路径读取主文档部件，提取段落及可读表格，按正文顺序输出，定位至少区分段落序号与表格行列。可识别标题样式与普通段落区分。对合并单元格避免同一内容重复索引；识别不了的复杂版式提示覆盖限制。

首版重点是正文和表格。文本框、批注、页眉页脚、嵌入对象、图片与复杂排版无完整覆盖承诺。未知范围不能标全覆盖；已知有遗漏时返回 PARTIAL 或明确 coverage 限制。不会执行宏或挂载对象，不访问外部关系，不把通用 ZIP 文件当成资料扫描。DOCX 内部读取限定必要部件，实施压缩体积、展开字节、条目数和解析时限约束。预期限额在发布配置确认，可注入小预算做测试。

加密或损坏分别报告；格式伪装、旧 .doc 或 .docm 不按 .docx 成功处理。空正文但含可读表格仍有效；只有嵌入图像时 EMPTY/NO_TEXT。超限只在已有可信段时返回 PARTIAL，否则失败。

## 验收

- F06-AC1 有段落、标题和表格交错的样本按顺序查询得到命中位置；合并单元格不重复。
- F06-AC2 加密、破损、伪装、预算耗尽分别可诊断；只有图片时无 OCR。
- F06-AC3 外部关系和嵌入对象不导致网络或额外文件读取，原 DOCX 保持不变。
