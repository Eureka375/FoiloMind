## 查询输入与交互

查询字段包括文件名/路径、正文关键词与结构化筛选。筛选按用户选定的授权范围、类别、标签、文档类型和明确日期字段组合。日期界面标注“修改时间”等实际含义，不从时间或文本推断学期和来源。支持仅筛选不输关键词；全部条件为空时显示已授权清单或提示输入，界面确定一个一致默认行为。

## 匹配与输出

- 工程基线是关键词之间按 AND、不同筛选维度按 AND。类别或标签维度允许多选，维度内默认为 OR。普通关键词采用确定的大小写及中文匹配策略，展示给用户；不静默翻译、同义词扩展或调用模型。
- 结果显示名称、真实当前路径、命中字段、正文实际命中片段和定位、索引状态/覆盖。正文不可读仍可匹配元数据；索引部分完成须明确范围与限制。
- 分页使用稳定排序。工程基线为完整名称命中优先，其后按其他匹配与时间排序，fileId 打破平局。允许按时间排序但不得改变查询授权。
- 从结果定位文件前重新确认当前可用性和读授权。外部移走的文件可显示路径失效，不把无索引、过期和无命中合并成同一提示。
- 仅对有效范围当前可发布索引检索。查询在后台运行，范围变化时丢弃旧结果。只有用户显式打开文件才交给系统关联程序；分析过程不运行文档。

## 验收

- F12-AC1 “Redis + PDF”命中未移动资料，显示含 Redis 的真实片段及页码。
- F12-AC2 中文词、多词、无查询仅筛选、多个维度及时间边界结果可预测；同批结果分页不重复。
- F12-AC3 未授权或不再可见数据不返回；无结果、索引过期和路径失效显示不同状态。
