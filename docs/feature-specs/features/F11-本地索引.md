## 数据流与职责

扫描时即为文件元信息建立索引，可读内容另外构建正文索引。索引派生自权威文件、提取结果和确认分类。保存授权范围、文档版本、覆盖状态、更新时间及真实片段引用；索引损坏可从允许保留的权威数据重建。搜索不中途重读原正文。

## 发布与失效

- 每次提交使用 scopeEpoch、scopeId、policyRevision、fileId、contentRevision 校验有效期；过期任务拒绝提交。索引构建记录视图版本，读侧只观察已提交版本及当前授权范围。构建失败/取消时不能暴露半成品或把整个范围标为 READY。
- 有真实提取段才纳入正文。解析失败的旧正文不能当作新版本可搜索；用户若看到元数据项，页面要说明正文不可用或待刷新。PARTIAL 只索引实际段及定位。
- 本地移动成功或可信外部改名通过 fileId 更新路径，索引不以旧/新路径当成两份文件；分类变化只更新关联字段。范围排除/撤销时读侧立即过滤，清理由 F14 执行。
- 允许保存正文或可重建段引用，按 F14 统一生命周期。普通日志只留故障码、范围和统计，不写完整命中文本。

## 验收

- F11-AC1 未移动文件已具备名称及正文索引，部分可读只命中已提取文本。
- F11-AC2 构建取消、失败、范围撤销及旧任务晚到不发布过时或越权正文。
- F11-AC3 改名保留 fileId，搜索只出现新位置；重新索引与重启后无重复记录。
