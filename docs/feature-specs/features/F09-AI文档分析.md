## 能力与交互

对用户明确选择分析的文档，或任务中需要语义判断的授权候选，分析主题与用途，返回可选短摘要、候选类别/标签及待核对原因；组级分析根据获准代表文件建议共同主题与组名。开启、调用策略及发布子集以评估定稿。界面标明建议来自 AI，展示真实依据和覆盖范围，允许采纳、编辑或丢弃。

## 契约与失效

- 只传任务许可范围内必要的结构字段及相关正文片段，带临时文件引用和片段 ID；没有任务需要时不传绝对路径。记录版本、模型及输入预算；解析不可靠、空正文、撤销授权时不向模型发送正文。组级请求只接受本批文件，禁止模型自行获取新内容。
- 单文档建议存为 Suggestion，组级建议存为 GroupSuggestion。已有类别必须指向本批允许 ID；新类别名只作为字符串建议。引用证据必须指向提交给模型的文件片段，由程序对照原文。组级结果随任一成员版本或授权失效。核验引用存在不代表模型推论正确，界面区分猜测和文档事实。
- 校验类型、字段长度、可选字段和引用范围。对输出中的路径、命令、授权、未知 ID 或其他不支持内容不执行；含非法结构的结果标为无效。对主题不确定不伪造证据或评分。
- 超时、模型不可用、响应无效、任务取消分别提示，其他文件可继续；保留规则建议和人工入口。提交前检查内容与授权版本，防止迟到响应复活旧记录。模型输出仅入建议表，无写分类和操作的权限。
- 默认本机模型接入，首版没有云端内容通道。选择具体模型、提示策略、调用时机、段长、并发数与超时上限在试测后冻结。自然语言查询由 F20 单独说明。

## 验收

- F09-AC1 假模型返回合法候选和可核验片段，UI 标来源；接受前不改变人工值，磁盘始终无变化。
- F09-AC2 响应含未知 ID、无效引用、正文诱导指令或超预算字段时，无越权读取、写入、联网或执行。
- F09-AC3 断开模型、注入超时并在请求中撤销授权，显示对应状态，普通搜索和人工管理仍可用。
- F09-AC4 用相同样本比较 F08 和 F09，记录准确性、人工修改量、摘要依据与耗时，发布承诺基于实测。
