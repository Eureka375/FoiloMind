## 输入与执行流程

仅接收由 F15 创建和固定的 planId/revision。先认领有效确认并校验计划内容。每项执行前写入可持久化意图，再核对授权、身份、原路径当前状态、内容证据、目标可写性及占用。每一步结果进入 F17。成功时用原 fileId 更新当前位置与显示名，刷新索引。

- 检查路径组件及最终对象；拒绝越界、绝对路径伪装、保留名、非法字符、尾随空格/点、设备/备用数据流路径、链接或无法验证的重解析路径。保持扩展名；先检测批内目标碰撞，按实际文件系统语义比较。
- 不覆盖已有文件，真实执行使用支持无覆盖语义的操作原语。目标在预检之后被占用也要安全失败。不会擅自加后缀；由用户编辑计划并重新确认。改名默认仅变更文件名。
- 通过受控句柄或等效方式将检查与操作绑定。若文件系统无法提供预期的身份验证、无覆盖或恢复保证，则拒绝该项。工程基线先支持经验证的同卷场景；跨卷、仅大小写改名、循环换位及需要依赖前项腾出目标的操作暂不执行，单独验证后才能启用。
- 允许在已确认边界内创建必要目标目录，创建计入任务记录。失败后避免清理任何非本任务创建或已被外部使用的内容。批内单项安全失败可继续独立项；取消仅停止后续项。磁盘结果不明确时交给 F17，禁止普通重试。
- 写授权仅对计划操作生效。位置变更后按 F02 为同一 fileId 重新计算读取归属，立即失效旧范围的索引，目标有读授权时再发布新索引。没有读授权时清空当前读取归属并隐藏文件与派生内容，所需路径证据由 F17 保留。磁盘成功而管理记录未同步时记录 PENDING_SYNC，仅补传管理数据，禁止重复移动。

## 验收

- F16-AC1 已确认移动和改名统一更新原 fileId、显示名及索引；目标不在读授权内时不暴露正文。
- F16-AC2 目标在确认后被占用、源被修改、目录链接变化、非法 Windows 名称时保留现状，不覆盖。
- F16-AC3 取消与部分失败逐项真实报告。模拟磁盘成功但元数据提交失败，历史可区分并按 F17 核对。
