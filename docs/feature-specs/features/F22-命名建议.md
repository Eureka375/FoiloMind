## 职责与候选流程

在用户主动选择时，根据已核实的主题、用途和文档元信息，展示一个可编辑名称建议。AI 可以理解文档主题和用途；结构化模板及实际文件名由本地程序生成。标题缺失可沿用原名。只有原始信息可核实才加入日期、作者或版本，不能从文件系统修改时间推断成文日期。

建议只含文件名，不含路径和操作。程序保留扩展名，按 Windows 规则处理非法字符、保留名、长度和冲突；无法安全变换时要求用户编辑。确认采用命名建议只修改草稿，真实改名必须走 F15/F16。建议改变不得使旧计划确认生效。

## 验收

- F22-AC1 含不明作者/日期的文档不凭空补写；保留原扩展名。
- F22-AC2 含路径分隔符、Windows 保留名或同名的建议不会产生未经确认的变更。
- F22-AC3 接受建议和取消预览均保持原件；真实改名属于固定计划并提供撤销条件。
