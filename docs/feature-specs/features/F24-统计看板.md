## 范围与口径

README 只列出看板作为后续增强，未冻结指标。建议从当前授权范围的文件数量、按格式分布、提取覆盖、待确认数量和索引状态开始。指标基于已保存状态计算，不为统计重新分析正文。需要展示物理任务时用历史逐项结果，撤销另计。

页面显示统计范围、更新时间、过滤条件和计数定义。文件总量按 fileId 去重；分类、标签分布允许一文件多类，注明类别合计可能大于文件总量。错误、进行中、部分覆盖与完成分别计数，过期或不完整数据明确标识。无数据与读取失败分开呈现。范围撤回立即移除相关统计贡献。

## 验收

- F24-AC1 同文件多个类别时总量只计一次，分类统计可分别计入，口径可核对。
- F24-AC2 范围过滤、撤销授权、索引未完成、数据读取失败不显示为完整统计。
- F24-AC3 不依赖模型或重新读文件，查看统计不改变原文件和分类。
