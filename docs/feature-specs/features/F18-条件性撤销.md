## 入口与反向计划

用户从历史选中已完成任务或符合条件的项。只考虑记录成功且尚未撤销的项；不确定项先走 F17。显示当前文件位置、拟恢复路径、不能恢复项及原因。恢复原名和原位置需审批同一份反向计划，重新校验当前访问/变更权限；撤销历史不自动重授权限。

## 条件与结果

- 按日志记录验证当前对象和内容证据，检查原位置是否空闲、两端路径是否仍有效、操作是否与更新的已完成任务冲突。内容已变、对象有歧义或位置被占用时跳过或失败，保护当前状态。
- 当任务有顺序依赖时按安全的反向次序执行；逐项无法独立安全逆转时拒绝。应用 F16 的无覆盖、竞态和文件系统限制。撤销变更前追加意图，成功后沿用 fileId，按 F02 重新计算读授权归属，再同步或隐藏索引；用户分类保留。
- 逐项显示已撤销、不可撤销、跳过和待核对。选择重试之前先核对原因消除，重新预检并确认。已撤销的项再次请求不能重复生效。
- 撤销恢复符合条件的名字和路径，不恢复历史正文版本，也不删除用户后来建立的目录或文件。

## 验收

- F18-AC1 确认前只提供预览；确认后符合条件的项回到原名和位置，内容不变。
- F18-AC2 原位置占用、内容被编辑、范围撤回或文件又被其他操作移动时，不覆盖、不丢修改。
- F18-AC3 部分恢复和重复请求结果可追溯，原执行事实与撤销事件均存在。
