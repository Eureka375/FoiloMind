## 职责与候选流程

用户显式启用后，只监听已授权目录，以轻量变化事件触发 F13 刷新。事件只是提示，不是可靠文件身份、删除事实或授权变化。未启用或不可用时手动刷新仍正常。配置更改、撤销或应用关闭时停止监听并丢弃旧授权事件。

对连续和重复事件做合并，限制队列，处理事件乱序、短时间重复保存和临时文件。事件溢出或监听断开时标为“建议手动刷新”，或者在同一授权下安排重新枚举，不能默默声称索引最新。身份和内容仍按 F13 判定。后台更新不能重写人工分类、自动调用未启用模型、自动移动或删除任何文件。

## 验收

- F25-AC1 重复保存、改名和删除最终与手动刷新一致，无重复记录。
- F25-AC2 发生溢出或关闭监听时状态透明，手动刷新可恢复。
- F25-AC3 撤权后取消订阅且迟到事件无效；人工分类和原文件保持。
