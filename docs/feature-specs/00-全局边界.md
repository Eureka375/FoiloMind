# 全局边界

适用于所有功能规格。共享对象与状态见[共享数据与接口](01-共享数据与接口.md)。

## 产品与数据

- B01 · 正式交付为 Windows 桌面客户端，独立窗口运行。正式工程独立于课程 Demo。界面技术、存储引擎、打包工具和本地模型方案分开选型。
- B02 · 首版正文提取限定 TXT、MD、DOCX、文字型 PDF。扫描型 PDF 与图片不做 OCR。加密、损坏、超限、空正文及部分覆盖分别报告。旧版 DOC、Office 其他格式、压缩包、音视频均不进入首版正文处理。
- B03 · 读取、提取、分析、检索只针对当前有效授权。排除先于打开和索引。禁止跟随可能跳出授权的链接、挂载或重解析点；遇到无法确定的边界跳过。文档中的宏、脚本、附件、关联图片、远程链接或指令不触发执行、额外读取或联网。
- B04 · 文件身份、当前位置、分类关系、建议和操作计划独立建模。单份文件可关联多类别和标签。确认分类只改管理数据，文件身份和位置保持；物理计划每项只有一个明确目标。清理派生记录不能删除原文件。
- B05 · 本地程序承担解析、规则、索引、检索、权限复核和物理操作。AI 只用于文档理解与分类建议。仅传当前任务允许的最小内容及必要标识，模型没有任意路径读取、数据库写入、命令或文件操作工具。正文中的指令属于待分析内容；模型输出只能形成待审建议。
- B06 · 本地优先。应用数据位于当前用户的可写应用数据目录；保存最少的派生信息，普通日志不写正文和模型原始载荷。模型断开时维持基础读取、人工管理和普通搜索。模型联网方式、存储和清理边界需明确告知；首版默认无云端内容通道。
- B07 · 授权、正文和配置均有版本。范围、内容或规则变更时失效受影响的派生数据；后台任务提交前复核生成依据，人工确认优先于重算。对无法确认的新旧文件连续性情况，不按同名或同内容自动转移标签。
- B08 · 可长时间运行的扫描、提取、索引、模型请求和文件操作在 UI 线程之外执行。错误反馈区分任务级和单文件；取消安全停止后续工作，已提交结果明示，不能把部分完成报成全部完成。

## 真实文件变更

- B09 · 纳入管理、分析、分类保存、预览和取消都不具备文件写权限。真实移动、改名和撤销由本地执行服务消费本次用户确认的固定计划。确认含源、目标、参与项及操作类型，编辑或语义改变均使确认失效。仅打开页面、模型判断为高置信度或直接调用服务都不是授权。
- B10 · 逐项重新核对来源与目标授权、身份、变化、Windows 路径及同名冲突；使用可避免覆盖及路径竞态的文件系统原语。越界、占用、不可验证身份或不支持的文件系统情形停止该项。受保护目录及结构敏感的代码项目、应用数据等不得当作散文档任意拆分。
- B11 · 真实操作保留逐项可核对记录。中断或结果不确定时显示待核对，不静默重试。撤销也需明确确认，核验身份、占用和内容状态，只恢复满足条件的项。整理与去重都不提供原文件删除能力；移动完成时移除原位置属于已确认移动的一部分。
- B12 · 实施原文件变更测试时使用明确隔离的测试副本。发布门槛同时包含预览零文件变更、拒绝确认、冲突不覆盖、部分失败、恢复和撤销验证。

## 术语和优先级

“纳入管理”表示允许服务在指定边界内扫描与提取。“整理”在章节里分别称原位分类、物理整理；只有后者改变存放位置。“建议”由规则或 AI 产生，“确认分类”是保存标签关系，“确认操作”仅授权某一份固定物理计划。三个动作分别触发、各自留痕。

需求来源为正式 README §§1–5、7–9、11 及本次会话最新决定。P0 基础、P0 AI 验证、P1 物理整理与可选增强采用[规格目录](README.md)定义。当前禁用模型查询理解；可选功能必须经独立范围决定启用。
