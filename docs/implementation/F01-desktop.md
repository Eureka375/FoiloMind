# F01 Windows 桌面与后台任务

正式工程采用 Python 3.11+ 和标准库 Tkinter/ttk。Windows 版 Python 提供 Tcl/Tk 及无控制台的 `pythonw.exe`，便于在当前阶段验证独立窗口。界面、应用任务和运行环境检查分为独立模块。任务在工作线程运行，以队列把不可变的进度和终态事件送回 UI 线程。当前一个窗口同时提交一个任务。取消在步骤边界生效，正在执行的步骤结束后更新实际计数；关闭窗口走同一条取消路径。

## Windows 启动

使用普通权限安装带 Tcl/Tk 的 Windows 版 Python 3.11 或更新版本。在仓库根目录双击 `launch.pyw`，或执行 `pythonw.exe .\launch.pyw`。打开“后台任务”，点击“检查运行环境”，可查看 Python 和 SQLite 检查结果。当前使用系统 Python 运行，独立发行包在 F19 验收。

## 验收范围

运行 `python -m unittest discover -s tests -v`。桌面测试需要 Windows 桌面会话。测试覆盖实际窗口、运行环境检查、慢任务期间重绘和取消、不定进度以及晚到事件隔离。

F01-AC1 的桌面启动和 F01-AC2 的任务基础可独立验收。F01-AC3 的事件隔离可独立验收，配置恢复随 F14 接入。无模型条件下的文档读取、分类、搜索和分类界面重启恢复，需要接入对应功能后联合验收。
