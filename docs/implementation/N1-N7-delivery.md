# FolioMind 首版实施与验收

以 [系统设计 v2](../FolioMind_System_Design_v2.md) 为业务基线。继续使用正式工程的 Tkinter、SQLite 和后台任务。涉及主分类数量、云端分析等差异以 v2 正文为准。

- [x] N1 · 用 22 份样本清单验证四格式、逐项解释、证据定位、排除和原件哈希。文件对话框支持目录和多文件，安装 tkdnd 后启用拖入。
- [x] N2 代码 · 固定发送范围并限制每批数量、文本和请求时间，支持兼容 Chat Completions 的 HTTPS 服务。用假模型验证分段、引用和过时结果。
- [x] N3/N4 代码 · 树形批量审核、独立接受分类/标签/拟用名称、手工编辑和云端文字修订，通过版本快照显示并确认可核验差异。
- [x] N5 · SQLite 保存来源、分类、索引和草案。支持手动刷新、忽略与恢复、分类树、关键词与条件筛选。三字符及以上优先使用 FTS5，短词回退至受限范围中的子串匹配。
- [x] N6 本地操作 · 对测试副本验证同盘移动、独立改名、冲突、日志、中断核对和批量撤销。发布候选的打包检查见下方记录。
- [ ] N7 实际对照 · 已运行规则基线并整理评估方法；实际模型与规则的对照、人工评价和答辩验收尚待进行。

测试环境使用 `tests/fixtures/n0-n1` 及临时目录。应用运行不得读取未授权范围或在未确认时变更原文件。真实模型评估需要用户配置实际服务并确认发送，不能用假响应冒充实测。

## 技术实现

- Windows UI 使用 Tkinter/ttk 和可选 tkdnd。继续使用现有工作线程将结果发送到主线程。取消会停在文件、分段或操作项边界，正在执行的云端连接受超时约束。
- TXT/MD 用严格 UTF-8（含 BOM）与原始行号。DOCX 用 python-docx 验证主文档段落与表格。PDF 用 pypdf 提取文字层；未进行 OCR。
- 启动配置继续放在原 SQLite 数据库。资料库默认位于同一用户应用数据目录下的 `library.sqlite3`。确认草案不会变更磁盘路径。来源撤回清理对应正文、索引和含该资料的草案历史。
- 云端客户端使用 Python 标准库 HTTPS，支持基于 API Key 的 Chat Completions 请求，密钥保存到 Windows 凭据管理器。提供方须通过连接测试。界面显示实际发送的范围，明确确认后开始；无上传权限的正文不发出。
- 实际整理使用 Windows 同盘文件句柄重命名，无覆盖。目标目录与文件身份变化时跳过或报错。跨盘、网络盘、链接路径和无法验证身份的对象不执行。普通错误提示不记录模型密钥和正文。

## 本地演示

1. 启动桌面应用。在“文件库”选择 [样本目录](../../tests/fixtures/n0-n1/样本目录)，启用递归，并填写 `资料/仅测试排除`。
2. 点击样本，查看段落/表格、页码和证据行。搜索“事务”或“复合索引”并核对实际命中的正文。纯扫描 PDF 无文字，混合 PDF 部分可读。
3. 在“AI 分析与审核”配置经允许的 HTTPS 服务、模型和密钥。可先点击“测试连接”，该请求不包含文档。选择留出集中的四份，在确认窗口核对待发送范围，再分析。
4. 在审核树查看依据，选择所需的确认项目。先预览一次文字或手动调整产生的草案差异，再保存变更。用测试副本离线演示实际移动、同名冲突及撤销。

## Windows 发布候选验收

使用 Python 3.13 x64 和 PyInstaller 6.22.3 构建，输出在 `dist/windows/FolioMind/`。应保留整个目录及 `_internal`，然后启动 `FolioMind.exe`。

当前 Windows 非管理员会话运行了 27 项自动测试。打包后的进程使用临时用户数据目录，清除了 Python、Conda、Tcl/Tk 的外部环境设置，并以仅系统目录作为 PATH，验证主窗口启动并正常退出，两个 SQLite 数据库成功建立。尚未在另一台全新 Windows 机器验证，也未生成签名安装程序。

## N7 规则基线记录

`python -m foliomind.evaluation tests/fixtures/n0-n1/expected.json --set development` 与 `--set holdout` 读取合成数据的人工参考。开发集 8 份，课程、用途、待审核标记分别命中 8、5、7 份。留出集 4 份，分别命中 4、3、2 份。留出集误差包括对跨课程案例未标待审核，以及根据文件和正文无法可靠确认课件用途。样本少，结果只描述本批。真实模型、人工修改量、费用与用户研究尚无实测。
