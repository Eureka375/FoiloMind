# F14 当前用户配置持久化

应用在 `%LOCALAPPDATA%\FolioMind\foliomind.sqlite3` 保存启动页和设置版本。设置保存在各自的 Windows 用户配置目录中，离线生效。应用运行时只需要用户配置目录的写入权限。

## 实现

- 使用 Python 标准库 `sqlite3`。新库在事务内建立初始配置并写入 `PRAGMA user_version = 1`。升级时按版本添加事务迁移。遇到未知结构或不兼容版本，应用保留数据库并在界面显示原因。
- “保存设置”使用带版本检查的事务，避免旧窗口覆盖已提交配置。界面在提交成功后显示保存结果。读取失败时仍可打开文件库和后台任务，设置页显示失败原因。
- 应用数据库当前只保存首选启动页及其版本，配置在被更新或由用户移除应用数据前保留。当前实现没有文件正文、索引、摘要、模型载荷及普通日志的落盘路径。

## 验收

1. 启动 `launch.pyw`，打开“设置”，选择“后台任务”，点击“保存设置”。
2. 关闭窗口并重新启动，确认直接进入“后台任务”。
3. 运行 `python -m unittest discover -s tests -v`。自动测试用两次独立的 Windows 进程验证配置恢复，并模拟 SQLite 写锁验证界面报错、旧值保留。测试也覆盖未知库版本、旧结构和并发窗口的配置冲突。

本阶段验证 F14-AC1 的配置路径、写失败和重启恢复。分类存储接入 F10 后联合验收。撤销授权和派生数据清理依赖 F02 及相应的生产链路，F14-AC2、AC3 随这些功能接入验证。
